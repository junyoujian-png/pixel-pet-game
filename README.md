# 🦊 Pixel Pet Game

A browser-based pixel pet game built with vanilla HTML / CSS / JavaScript.

## Features

- Pixel fox pet drawn in SVG (`image-rendering: pixelated`)
- Pet info card with name, rarity badge, level, and EXP progress bar
- Stats: age, weight, mood, hunger — with passive decay over time
- Actions: feed, 25-min Pomodoro focus timer, todo list, cosmetics
- Coin system with shop (food & equipment tabs)
- Auto level-up with toast notification
- `localStorage` save — progress persists across sessions
- Dark mode (`prefers-color-scheme: dark`)
- Mobile-first responsive design (max-width 430 px)

## Play

Open `index.html` directly in a browser, or visit the live GitHub Pages site.

## Stack

Plain HTML · CSS · JavaScript — zero dependencies.
